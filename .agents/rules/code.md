Untuk konten tab `BottomNavigationBar` yang berat, wajib lazy loading keep-alive: tab dibangun hanya saat pertama kali dibuka, dirender dengan `IndexedStack` — anak yang sudah dibangun dibungkus `SizedBox.expand`, tab yang belum pernah dibuka memakai placeholder `SizedBox.shrink()` — agar state tab terjaga dan tab yang belum dibuka nol biaya layout. Skill terkait: `performa-aplikasi` (`.agents/skills/code/performa-aplikasi/SKILL.md`).
2. Untuk notifier Riverpod berbasis codegen, `build()` wajib mengembalikan state immutable Freezed; method reload (mis. `muatUlang()`) wajib memakai `AsyncValue.loading()` + `AsyncValue.guard(...)`; nama provider codegen = nama class tanpa akhiran `Notifier` (camelCase, mis. `PenggunaAktifNotifier` → `penggunaAktifProvider`). Skill terkait: `riverpod-pola` (`.agents/skills/code/riverpod-pola/SKILL.md`).
3. State Riverpod wajib `@freezed` dengan `const factory` dan `@Default` literal konstan (mis. `@Default([])`, `@Default(0)`), dengan private constructor `const NamaState._()` bila ada getter/method. Skill terkait: `model-state-freezed-abstract` (`.agents/skills/code/model-state-freezed-abstract/SKILL.md`).
