Operator `!` (null assertion) DILARANG digunakan untuk memaksakan nilai nullable menjadi non-null; wajib gunakan **type promotion via variabel lokal**: salin nilai nullable ke variabel lokal (`final x = nullableValue`), lalu gunakan variabel lokal dalam `if (x == null) return;` atau `if (x != null) { ... }` sehingga Dart mempromosikan tipe secara otomatis. Berlaku untuk field model, property widget (`widget.pelanggan`), return value fungsi, dan semua ekspresi nullable. Contoh benar: `final pelanggan = widget.pelanggan; if (pelanggan == null) return; _namaController.text = pelanggan.nama;`. Contoh salah: `_namaController.text = widget.pelanggan!.nama;`. Skill terkait: `type-promotion-null-safety` (`.agents/skills/type-promotion-null-safety/SKILL.md`).
