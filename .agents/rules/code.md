1. Untuk konten tab `BottomNavigationBar` yang berat, wajib lazy loading keep-alive: tab dibangun hanya saat pertama kali dibuka, dirender dengan `IndexedStack` — anak yang sudah dibangun dibungkus `SizedBox.expand`, tab yang belum pernah dibuka memakai placeholder `SizedBox.shrink()` — agar state tab terjaga dan tab yang belum dibuka nol biaya layout. Skill terkait: `performa-aplikasi` (`.agents/skills/code/performa-aplikasi/SKILL.md`).
2. Untuk notifier Riverpod berbasis codegen, `build()` wajib mengembalikan state immutable Freezed; method reload (mis. `muatUlang()`) wajib memakai `AsyncValue.data(await _ambilSemua())` + `catch (e, s)` dengan logging `L.e(...)` dan **wajib `rethrow;`** (tanpa `AsyncValue.loading()` / `AsyncValue.guard`); nama provider codegen = nama class tanpa akhiran `Notifier` (camelCase, mis. `PenggunaAktifNotifier` → `penggunaAktifProvider`). Skill terkait: `riverpod-pola` (`.agents/skills/code/riverpod-pola/SKILL.md`).
3. State Riverpod wajib `@freezed` dengan `const factory` dan `@Default` literal konstan (mis. `@Default([])`, `@Default(0)`), dengan private constructor `const NamaState._()` bila ada getter/method. Skill terkait: `model-state-freezed-abstract` (`.agents/skills/code/model-state-freezed-abstract/SKILL.md`).
4. Data dummy model wajib mengikuti pola: kelas `abstract final class <Nama>Dummy` di `lib/fitur/<fitur>/dummy/<model>_dummy.dart`; `dummyList` `static final List`; setiap id memakai konstanta `static const` SCREAMING_SNAKE_CASE berformat UUID `8-4-4-4-12` (nibble versi `4`/varian `8`); tanggal entri relatif terhadap `DateTime.now()`. Skill terkait: `data-dummy` (`.agents/skills/code/data-dummy/SKILL.md`).
5. Setiap model yang berkaitan dengan database (SQLite, Supabase, Firebase, dll.) wajib mendefinisikan konstanta nama tabel dan kolom melalui kelas `abstract final class <Model>Skema` terpisah di berkas model yang sama, lalu memakainya via interpolasi `${XxxSkema.*}` di DDL, query, dan migrasi — bukan string literal; nilai konstanta kolom wajib cocok persis nama kolom DB. Skill terkait: `konstanta-skema-tabel` (`.agents/skills/code/konstanta-skema-tabel/SKILL.md`).
6. Setiap pemanggilan `L.e(...)` (error log) wajib menyertakan stack trace dengan interpolasi `$e $s`; dilarang memanggil `L.e` tanpa `$s`. Skill terkait: `logging-debug` (`.agents/skills/code/logging-debug/SKILL.md`).
7. Anak `IndexedStack`/tab yang memakai `AutomaticKeepAliveClientMixin` wajib menyertakan `wantKeepAlive => true` dan pemanggilan `super.build(context)` di `build()`; keep-alive yang tidak diperlukan wajib menghapus mixin sepenuhnya (tab yang selalu dibangun di `IndexedStack` tidak wajib mixin). Skill terkait: `performa-aplikasi` (`.agents/skills/code/performa-aplikasi/SKILL.md`).
8. Dilarang membuat kelas/wrapper log manual per proyek (mis. `lib/debug/log.dart` dengan `class Log`/`_formatData`/`_logCustom`); seluruh logging wajib memakai `L` dari `share_global_saya` (`package:share_global_saya/src/utils/l.dart`: `L.i`, `L.s`, `L.w`, `L.e`, `L.json`, `L.list`, `L.api`); wrapper manual yang sudah ada wajib dihapus dan pemakaiannya dimigrasikan ke `L`. Skill terkait: `logging-debug` (`.agents/skills/code/logging-debug/SKILL.md`).
