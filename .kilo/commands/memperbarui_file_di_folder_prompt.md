# Memperbarui File Di Folder Prompt

1. Baca `AGENTS.md` terlebih dahulu dan patuhi aturannya.
2. Baca `instructions` pada `.kilo/kilo.jsonc` dan patuhi aturan yang terdaftar.
3. Diskusikan isi `$ARGUMENTS` agar menjadi baik dan benar; usulkan tambahan agar tidak ambigu/kurang jelas; perbaiki typo dan salah penempatan.
4. Setiap berkas di `prompt/` wajib hanya poin pentingnya saja; tidak bertele-tele dan tidak terlalu detail.
5. Jangan mengedit tanpa persetujuan pengguna; tampilkan dulu, lalu tunggu persetujuan.
