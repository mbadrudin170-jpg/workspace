# Memperbarui File Di Folder Prompt

1. Baca `AGENTS.md` terlebih dahulu dan patuhi aturannya.
2. Diskusikan isi berkas `prompt/` yang ditunjuk `$ARGUMENTS` agar baik dan benar; usulkan perbaikan bila ambigu/kurang jelas; perbaiki salah ketik/penempatan; tampilkan draf sebelum mengedit.
3. Setiap berkas di `prompt/` hanya memuat poin-poin penting (ringkas), bukan isi final/bertele-tele.
4. Jangan mengedit tanpa persetujuan pengguna; tampilkan dulu, lalu tunggu persetujuan eksplisit setelah draf ditampilkan.
5. Setelah mengedit, jalankan `formatmd` (alias: `npx prettier --write "**/*.md"`) untuk merapikan berkas Markdown.
