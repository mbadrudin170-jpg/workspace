# Cari Rules, Commands, Skill Yang Diinginkan

1. Baca `AGENTS.md` terlebih dahulu dan patuhi aturannya.
2. Baca `instructions` pada `.kilo/kilo.jsonc` dan patuhi aturan yang terdaftar.
3. Tambahkan argumen untuk mengetahui apa yang sedang pengguna cari; jika argumen kosong, tanyakan kepada pengguna.
4. Carikan di seluruh rules (`.agents/rules/`), skill (`.agents/skills/`), dan command (`.kilo/commands/`) apakah ada yang sesuai.
5. Carikan juga di `AGENTS.md` (root) selain rules, skill, dan command.
6. Tampilkan hasil pencarian sebagai daftar beserta path file yang sesuai.
