file : [kerjakan_prd](../../.kilo/commands/prd/kerjakan_prd.md)

1. **Tujuan:** mengimplementasikan PRD target secara utuh, dari pemeriksaan bentrok hingga verifikasi dan pembersihan akhir.
2. **Ketentuan umum:** baca `AGENTS.md`, seluruh berkas `.agents/rules/`, dan skill terkait (termasuk `format-prd`); patuhi semuanya. Gunakan bahasa Indonesia baku. Muat skill yang trigger-nya terpenuhi sebelum mengubah kode.
3. **Cakupan:** berkas PRD target di `prd/` dan seluruh berkas pada bagian "File-File Terdampak". Langkah final juga menyentuh status/penghapusan berkas PRD target dan pembersihan section terkait pada `refrensi_apk.md` (bila ditandai nama berkas PRD).
4. **Parameter `$ARGUMENTS`:** path berkas PRD (mis. `prd/prd_contoh.md`). Jika kosong, tidak ditemukan, atau statusnya sudah `Sudah Diimplementasikan` → **STOP** dan tanyakan via tool `question`.
5. **Alur kerja:** **Analyze** (baca PRD, daftar `File-File Terdampak`, dan PRD lain berstatus `Belum Diimplementasikan`/`Sedang Diimplementasikan`). **Plan** (periksa bentrok: file sama dengan bagian perubahan beririsan → bila bentrok, **STOP** tanpa mengubah berkas apa pun dan tanpa memperbarui status, lalu laporkan ke pengguna). **Execute** (ubah `Status Implementasi` menjadi `Sedang Diimplementasikan`, implementasikan seluruh kebutuhan). **Review** (jalankan `dart format`, `dart analyze`, `flutter test` bila relevan; pastikan tidak ada perubahan di luar cakupan). **Final** (ubah status menjadi `Sudah Diimplementasikan`, hapus berkas PRD, hapus section terkait pada `refrensi_apk.md` bila ditandai nama berkas PRD).
6. **Format laporan:** tabel `Item PRD | Berkas diubah | Verifikasi | Status` serta konfirmasi status PRD dan penghapusan referensi terkait.
7. **Larangan:** jangan mengimplementasikan PRD yang bentrok; jangan mengubah berkas di luar cakupan (termasuk "File-File Terdampak" dan pembersihan final yang disebutkan); jangan menghapus PRD sebelum implementasi diverifikasi; jangan menandai `Sudah Diimplementasikan` tanpa verifikasi; jangan commit/push tanpa perintah eksplisit pengguna.
8. **Selesai/STOP:** selesai bila seluruh kebutuhan terimplementasi, verifikasi lulus, status diperbarui, dan referensi dibersihkan. **STOP** (tanyakan via tool `question` bila perlu keputusan) bila bentrok, PRD tidak ditemukan, atau verifikasi gagal dan tidak dapat diselesaikan.
9. **Pemeriksaan bentrok wajib:** sebelum mengerjakan, periksa berkas terdampak; jika bentrok (file sama, bagian perubahan beririsan) dengan PRD berstatus `Belum Diimplementasikan` atau `Sedang Diimplementasikan`, **STOP** dan laporkan ke pengguna (tanyakan via tool `question` bila perlu keputusan).
