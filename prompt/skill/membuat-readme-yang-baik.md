1. Panduan menyusun `README.md` proyek yang informatif, terstruktur, dan memudahkan pengguna/kontributor memahami proyek.

2. Bagian wajib: Judul, Deskripsi, Instalasi & Menjalankan, Penggunaan, Kredit, Lisensi.

3. Bagian tambahan: Table of Contents, Badges, Kontribusi, Test, Daftar Kontributor, Demo Visual (GIF/screenshot).

4. Prinsip penulisan: menjawab what/why/how; bahasa Inggris (global); up-to-date.

5. Perbedaan tipe proyek: aplikasi vs library vs package vs non-code.
